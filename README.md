# mazeX
A python package to generate, represent, simulate and analyse mazes and spatial navigation tasks.

## Install
1. Install requirements from environment_m311.yml and environment_m311_pip_requirements.txt
2. Additionally requires specific fork branch of diskcache:
    1. `git clone https://github.com/schmoelder/python-diskcache`
    2. `git checkout support_dill`
    3. `conda develop python-diskcache`
